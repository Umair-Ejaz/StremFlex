# StreamFlix - MERN Video Streaming Platform

A full-stack video streaming application built with React, Node.js, Express, MongoDB, and Socket.io.

## Features
- 🎥 Video Upload & Local File Storage
- 💬 Real-time Comments & Replies via Socket.io
- 👍 Interactive Likes & Emoji Reactions
- 🔐 JWT Authentication & Protected Routes

## Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, Lucide React
- **Backend:** Node.js, Express.js, Multer
- **Database:** MongoDB & Mongoose
- **Real-time:** Socket.io
